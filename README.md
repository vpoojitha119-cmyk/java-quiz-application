# Java Quiz Application

## About the Project
A simple Java-based quiz application that tests the user's basic Java knowledge through multiple-choice questions.

## Features
- Five multiple-choice questions
- Automatic score calculation
- Displays the correct answer for wrong responses
- Validates user input
- Calculates the final percentage
- Allows the user to play again

## Technologies Used
- Java
- Scanner class
- Arrays
- Loops and conditional statements

## How to Run
1. Install the Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program using `javac Main.java`.
5. Run the program using `java Main`.
